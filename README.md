# EWP Job Board Plugin

## Description
EWP Job Board is a WordPress plugin designed to manage job listings efficiently. It provides an intuitive admin interface for creating, editing, and displaying job postings.

## Features
- Custom post type for job listings
- Admin interface for managing job postings
- User-friendly design with CSS styling
- JavaScript enhancements for interactivity

## Installation
1. Download the plugin files.
2. Upload the `ewp-job-board` folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the 'Plugins' menu in WordPress.

## Usage
- After activation, navigate to the "EWP Job Board" menu in the WordPress admin dashboard.
- Use the interface to add, edit, and manage job listings.
